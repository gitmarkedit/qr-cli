# qr

Минималистичный генератор QR-кодов для macOS в терминале на движке Rust (`qrtool`).

Поддерживает огромные ссылки (до 2953 байт, включая длинные конфигурации Happ / V2Ray / Clash), автоматическую очистку от переносов строк, автооткрытие в окне «Просмотр» (Preview) при превышении ширины терминала и кнопочное TUI-меню со стрелочками без цифр.

```text
qr (macos • rust)
────────────────────────────────────────────
буфер: https://github.com/rust-lang/rust (33 симв.)
────────────────────────────────────────────
  › • ссылка из буфера
    · ввести вручную
    · сеть wi-fi
    · скопировать png в буфер
    · выход
```

## Возможности

- **TUI меню без цифр:** навигация стрелками `↑` / `↓` и подтверждение `Enter`.
- **Монохромный минимализм:** без цветных эмодзи и кричащих плашек — чистый текст и точки в тон шрифта.
- **Интеграция с буфером обмена:** моментально подхватывает скопированную ссылку (`Cmd+C` → запуск `qr` → готово).
- **Поддержка огромных ссылок:** автоматическое включение Level L (до 2953 байт) и удаление случайных переносов строк.
- **Умный вывод:** если QR-код шире окна терминала, автоматически генерируется и открывается чёткий PNG в окне «Просмотр» (macOS Preview).
- **Мастер настройки Wi-Fi (`qr -w`):** быстрое создание QR для подключения к домашней сети.
- **Копирование картинки в буфер (`qr -c`):** копирует сгенерированный PNG в буфер обмена для мгновенной вставки (`Cmd+V`) в Telegram / Slack.

## Установка

```bash
git clone https://github.com/<ваш-аккаунт>/qr-cli.git
cd qr-cli
./install.sh
```

Или вручную:
1. `brew install qrtool`
2. Скопируйте файл `qr` в любую папку из `$PATH` (например, `~/.local/bin/qr`) и сделайте исполняемым (`chmod +x ~/.local/bin/qr`).

## Использование

### Интерактивный режим (без аргументов)
```bash
qr
```

### Командная строка с флагами
```bash
qr "https://example.com"                # быстрая генерация
qr -w                                  # мастер wi-fi сети
qr -c "https://t.me/channel"           # скопировать png в буфер обмена
qr -s ~/Desktop/code.png "текст"       # сохранить в файл
qr -i "https://example.com"            # инверсия (для светлых тем терминала)
cat config.txt | qr                    # передача через пайп
```
